## Ограничения, которые нельзя называть закрытыми

- Нет клиентских ID в реальных детализациях: тест уровня клиента синтетический.
- Нет точных длительностей stockout: исходные нули дают предупреждение, а не
  вымышленные дни. Численная компенсация требует подтверждённого ввода.
- Нет актуального свободного остатка IEK; пустые количества в поставках не приравнены
  к нулю. Этим объясняется большая доля заблокированных реальных строк.
- Нет расшифровки политики категорий и сроков поставщика. Категории — исходные коды,
  срок и горизонт — явные параметры. Backend допускает заданный менеджером горизонт
  по категории, UI предоставляет отбор по категориям.
- CSV не проверен на импорт в конкретную 1С. Экономический эффект и точность реального
  прогноза не оценивались. Полное прохождение пяти Must have не заявляется.
